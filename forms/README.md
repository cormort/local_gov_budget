# 固定表單範本（取代線上表單的查填流程）

全程在 GitHub Pages 上的靜態頁面完成，不需伺服器；填報資料只存在填表人的瀏覽器與回傳的 JSON 檔。

| 步驟 | 誰 | 做什麼 |
|---|---|---|
| 1. 建表單 | 承辦 | 首頁上傳 Excel 範本 → 確認欄位與公式 → 「匯出範本」得到 `名稱.json`；同一區塊可「下載查填用 Excel」給習慣用 Excel 的填報人 |
| 2. 發布 | 承辦 | 把 `名稱.json`（或直接把 Excel `名稱.xlsx`）放到本資料夾，commit 並推上 `main`；部署完成後網址生效 |
| 3. 發起調查 | 承辦 | 管理頁（`manage.html`）以這份範本發起調查專案（代號、發起單位、用途、期間、應繳機關），首頁「調查專案」複製查填連結 `?survey=代號` 寄給填報人 |
| 4. 填報 | 各機關 | 開啟 `https://帳號.github.io/local_gov_budget/?survey=代號`（本站帳號為 cormort；自行架設見 [`docs/setup.md`](../docs/setup.md)），填寫（可手填或「匯入已填 Excel」）後「匯出 JSON」或「匯出 Excel」，以 email 等方式回傳 |
| 5. 彙整 | 承辦 | 首頁「調查專案」按「彙整」（`form-aggregate.html?survey=代號`），把所有回傳的 JSON（或各機關「匯出 Excel」的檔案；其他 Excel 以檔名當機關名稱）一次拖入 → 繳交清單／依項目彙總／明細 → 「匯出 Excel」 |

- **正式收件請寄 `?survey=` 連結。** `?form=名稱` 範本連結仍可填，但沒有應繳名單、截止提醒與調查代號，彙整時無法對帳已繳／未繳。
- 修改同名範本即更新表單；已開啟舊版的人重新整理即可。
- **多個工作表要填的表單**請發布「匯出範本」的 `.json`（直接放 `.xlsx` 只會用第一個工作表）；彙整時也建議先拖入這份範本 `.json`，再拖入各機關回傳的檔案。
- `?form=名稱` 先找 `名稱.json`，沒有才讀 `名稱.xlsx`；兩者都在時以 .json 為準（改版請改同一種檔案）。
- 彙整只接受同一份表單（表頭與公式相同）的 JSON；Excel 只比對欄名須與第一份相同。同機關同年度重複繳交以最後匯入者為準。
- 彙總時公式欄以加總後的數值重算（比率類欄位才正確）。
- 「各填各的」清單型表（例如每個基金只填自己那一列）：彙整頁自動檢查**重複填報**——同一項目有多份檔案填了數字時列出來讓你勾選採計哪一份（數字完全相同時預設只採計第一份）；也可手動切換「每個項目只應由一份檔案填報」。
- 依項目彙總多一欄「狀態」：❌ 未填報（沒有任何一份填數字）、⚠️ 重複、✅；明細只列有數字的列，空白列略過。

## 範本庫管理（manage.html）

首頁「範本庫」右上角「管理範本與調查」。貼上 GitHub fine-grained 權杖（只給本 repo 的 Contents: Read and write）後，可以：

- 每份範本對應一個固定的查填網址（`?form=檔名`），清單上直接顯示並可複製；可依名稱、說明、分類、年度搜尋，或只看隱藏的
- 上傳／覆蓋範本（`.json` 或單一工作表 `.xlsx`，上傳前會先檢查是否能產生表單）
- 編輯發起單位、分類、用途、說明、年度、發起日期、截止日、隱藏 → 存在 `forms/index.json`；隱藏的範本不列在首頁，但連結照樣能用
- 依發起日期、截止日自動標示「未開始／進行中／已截止」，首頁範本庫與管理頁都可依狀態篩選
- 改名（舊連結會失效）、刪除（只能從 GitHub 歷史找回；不想列出請改用隱藏）

**分享連結會變嗎？** 用同一個檔名重新上傳、改分類／說明／年度／截止日、設為隱藏 → 不變；改名、刪除 → 舊連結失效；GitHub 帳號或專案名稱改了 → 網址前半段都會變。每年同一份調查可沿用同一張表（用「年度」區分）；欄位每年不同就每年一個新檔名，舊年度設為隱藏。已寄出的連結盡量不要改名。

首頁範本庫也可依名稱、說明、分類、年度搜尋，或選分類篩選。權杖只存在該瀏覽器分頁（sessionStorage），關閉即清除。首頁範本庫的每個表單另有「查填用 Excel」，可直接下載空白查填檔。

### 日常流程（範本庫建好之後）

1. **發起調查**：首頁「範本庫」分頁按「以此範本發起調查」（或「管理範本與調查」→「調查專案」），填調查代號、名稱、發起單位、用途、年度、發起日、截止日、應繳機關（每行一個）
2. **發出查填**：首頁「調查專案」分頁 →「複製查填連結」（`?survey=代號`）寄給填報人；習慣用 Excel 的另寄「查填用 Excel」（含調查代號）
3. **彙整**：該專案按「彙整」（已載入範本與應繳名單）→ 把回傳的 JSON／Excel 一次拖入 → 繳交清單看已繳／未繳 → 匯出 Excel
4. 同一份範本下一年再調查，就再發起一個新專案（如「114決算購建」「115決算購建」），網址、繳交清單、彙整各自分開

調查專案存在 `surveys/index.json`，由管理頁維護；範本的分類、說明、隱藏存在 `forms/index.json`。
