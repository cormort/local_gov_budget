📝 Sample JSON 快速編輯器（貼上式）

流程：選編輯目標 → 從 Excel 複製貼上資料 → 預覽 → 套用 → 下載修改後 JSON。→ 回主程式

① 選擇編輯目標

② 從 Excel 複製貼上

格式：每行一項，項目名稱＋（Tab 或多空白）＋數值。可包含千分位逗號。空白／單欄列當註解略過。
業務計畫表的層級用全形空格縮排：「項目」=L1、「　項目」=L2、「　　項目」=L3、「甲、基金來源：」=L0。

③ 預覽 / 套用後資料

黃底＝更新欄位 綠底＝新增列 灰字＝原資料（未動）

④ 下載

下載後請把檔案放回專案根目錄（覆蓋舊檔），commit 上 GitHub 後 Pages 會帶到新版。
