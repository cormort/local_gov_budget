# local_gov_budget — Excel 收件與貼表

**主要流程（首頁）**：寄出空白 Excel → 各機關照原本方式填好寄回 → 承辦在「貼表」頁把寄回的檔案一次拖入，依標準機關順序一列接一列貼成一張彙總表（保留原格式、重算合計與小計）下載。填報人不用碰網站。
全部是靜態頁面，沒有後端；檔案只在承辦的瀏覽器裡處理。

網站：https://cormort.github.io/local_gov_budget/

| 頁面 | 用途 |
|---|---|
| `index.html`（首頁） | 列出有空白 Excel（`forms/名稱.xlsx`）且登記在 `forms/index.json` 的範本，各有「下載空白 Excel」「貼表」；帶 `?form=`／`?survey=` 的舊連結自動轉到進階功能頁 |
| `paste.html`（`?form=名稱` 選用） | 貼表，兩種貼法（自動判斷，可切換）。**依項目填入**（每份都有全部基金、各填自己那一列，例：決算執行情形）：依第一欄名稱對位填進範本（名稱不同時以標準基金名單對照）；欄數與範本相同照位置、不同（有人插欄）依表頭文字對位；同一檔同一欄同一個非零數字出現 3 列以上視為往下拖曳，只採最上面一格；多份檔案填同一列時採檔名認得出是該基金的那份，只有別的機關填的照填但標淺橘色並加註解；沒人填的基金、範本沒有的列與欄、沒填任何資料的檔案都列在「查對」（頁面＋下載檔多一張工作表）。也讀 .xls、.ods。**接續貼上**（協商表）：不需要先存範本，版面依第一個拖入的檔案；從範本庫開啟（帶 `?form=`）則讀 `forms/名稱.xlsx`。取第一個沒隱藏的工作表當底，表頭到「合計」列（沒有就到表頭最後一列）照抄；各回傳檔同名工作表的合計列以下、說明列（「註」開頭）以上的列依序貼上，略過空白列與佔位列（範本原有的列，以及含 ＯＯ／ＸＸ／○○、【範例 開頭的列），標題列的合併儲存格照搬；範本合計、小計列有 COUNTIF 的欄改成新範圍的公式、「共…案」重算；說明列移到最後；其他工作表不帶。機關從檔名辨識，依 `surveys/orgs.json` 順序排列，認不出的排最後；可用 ↑ ↓ 調整順序、移除檔案，之後再拖入的檔案依標準順序插入、不打亂手動順序。「指定範本檔」可選一份空白 Excel 當版面（不貼入），已讀入的檔案會依新版面重算；每個檔案的工作表預設取與範本同名的那張，可在順序表逐檔改選（換範本後仍保留手選的） |

新增範本：管理頁（`manage.html`）上傳空白 Excel，再到「說明」填一句用途（首頁只列 `forms/index.json` 有登記、沒隱藏的範本）。

## 進階功能（`advanced.html`）：網頁查填與調查專案

用 GitHub Pages 取代線上表單：上傳 Excel 範本產生表單 → 各機關填寫並匯出 JSON 回傳 → 承辦彙整並匯出 Excel。

四大部分：**範本庫**（可重複使用的表單）→ **調查專案**（一次實際收件：範本＋發起單位、用途、期間、應繳機關，各有自己的查填網址）→ **查填**（填報人）→ **彙整**。
（舊網址 `form-builder.html` 與首頁帶 `?form=`／`?survey=` 的連結都會轉到 `advanced.html` 並保留參數，已寄出的查填連結照樣能用）

| 頁面 | 用途 |
|---|---|
| `advanced.html` | 進階入口，四個分頁：**調查專案**（進行中／未開始／已結束，複製查填連結、查填用 Excel、彙整）、**範本庫**（建立新範本、以此範本發起調查）、**查填**（進行中的調查）、**彙整** |
| `?survey=代號` | 調查專案的查填頁：顯示專案名稱、發起單位、用途、期間；機關欄有應繳名單可選；回傳檔帶調查代號 |
| `?form=名稱` | 範本預覽／舊連結：讀 `forms/名稱.json`，沒有則讀 `forms/名稱.xlsx`（沒有專案資訊） |
| `manage.html` | 範本與調查管理（GitHub 權杖）：發起與編輯調查專案（範本、代號、發起單位、用途、年度、發起日、截止日、應繳機關、隱藏、提前結束），上傳／改名／刪除範本與分類、說明 |
| `form-aggregate.html` | 彙整；`?survey=代號` 先載入該專案的範本與應繳名單，繳交清單列出已繳／未繳／不在名單，別的調查的回傳檔會擋下 |
| `surveys/orgs.json` | 標準機關名單（沿用 excel_merge 的 fund-config.json）：`sortOrder` 是標準名稱與順序，管理頁可一鍵帶入應繳名單；`aliasMap` 是簡稱對照（台電 → 台灣電力股份有限公司）。彙整時回傳檔的機關名稱依序以完全相同／別名、去掉「基金」字尾、前 4 字＋字數相同、包含名單名稱比對，模糊比對只在唯一時成立，並在狀態欄註明對應到名單的哪一個 |

> **寄給填報人的是調查連結 `?survey=代號`，不是範本連結 `?form=名稱`。** 範本連結仍可填寫，但沒有應繳名單、截止提醒與調查代號，彙整時無法對帳已繳／未繳。

發布表單與完整流程見 [`forms/README.md`](forms/README.md)。

**想要有自己的一份？** 從申請 GitHub 帳號、Fork 到開啟 GitHub Pages 的步驟見 [`docs/setup.md`](docs/setup.md)。

## Excel 範本規則

- 範本有多個工作表時，勾選要填寫的工作表（預設第一個沒隱藏的），每個工作表是一個分頁；匯出的 JSON、查填用 Excel、彙整都依工作表分開
- 匯入已填 Excel、彙整時依工作表名稱對應；改過名的工作表只認名稱開頭 4 字相同、欄名一致的（避免把「113非營業(供參)」這類往年資料當成今年的表）
- 常見格式：第 1 列表名、第 2 列單位、第 3 列起是欄位（可多層合併）。表頭上方的表名、單位列會略過並顯示在表格上方：只有一格字、每格都是「標籤：值」（單位：千元、填表機關：），或第一欄橫向合併超過半寬的列都算；第一欄是項目名稱，表頭下方的資料列成為預設項目
- 表頭可用合併儲存格做多層（例：「預算數」橫跨「原編／增減／核列」），欄名串成「預算數－原編」，表單顯示對應的多層表頭；只有一格有字的列（表名、「單位：千元」）會略過
- 同一列的公式（`+ - * /`、括號、`SUM(B2:D2)`）→ 自動計算欄；跨列、跨工作表或其他函數會提示並改為手填
- 有文字資料的欄位是文字欄；空白欄預設為數值欄

## 開發

```bash
npm install
npm test            # 公式轉換與求值、貼表的自我檢查
npm run build:css   # 由 src/input.css 重建 budget-style.css（掃描根目錄所有 *.html、*.js）
python3 -m http.server 8000   # http://localhost:8000/
```
