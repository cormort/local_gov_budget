發起新調查

每次實際收件是一個調查專案：用哪份範本、發起單位、用途、期間、應繳機關。每個專案有自己的查填網址，寄給填報人；收件後按「彙整」。

分享連結會變嗎？
查填網址是 …/local_gov_budget/?survey=調查代號。 如果這個網站是 Fork 到自己帳號的，網址要換成自己的帳號與專案名稱（https://你的帳號.github.io/你的專案名稱/?survey=調查代號），不要沿用原作者的網址；用「複製查填連結」按鈕複製的會自動是目前這個網站的網址。
做了什麼連結
修改專案的名稱、發起單位、用途、期間、應繳機關，或設為隱藏不變
修改專案用的範本內容，用同一個檔名重新上傳不變（填報人開到的是新版）
刪除專案，或刪除它用的範本失效
GitHub 帳號或專案名稱改了網址前半段都會變

建立新範本

上傳 Excel 範本，自動產生表頭與表單，再按「匯出範本」發布到範本庫（或到管理頁直接上傳）。

範本規則

範本規則：第一個非空白列為表頭（可用合併儲存格做兩層表頭，欄名會成為「預算數－原編」；只有一格字的表名、單位列會自動略過），第一欄為項目名稱。第二列起的資料會帶入為預設項目； 儲存格若是公式（如 =B2-C2、=SUM(B2:D2)，限同一列的加減乘除），該欄即成為自動計算欄。項目名稱以「一、」「（一）」「1.」「（1）」編號時，上層項目的數值自動等於下層加總；沒有編號的合計、小計公式列會略過，由表尾合計自動計算。空白欄預設為數值欄；要文字欄請在任一資料列填入文字。

範本庫

可重複使用的表單（欄位、項目、公式）。要收件時，按「以此範本發起調查」建立調查專案。
