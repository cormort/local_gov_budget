範本庫管理

上傳、更新、改名、刪除 forms/ 裡的範本，編輯分類、說明、年度、截止日與是否隱藏

1. 連線 GitHub

貼上 GitHub 存取權杖（token）才能修改範本庫。權杖只存在這個瀏覽器分頁，關掉分頁就清除；不會送到 GitHub 以外的地方。

怎麼取得權杖？
  1. 登入 GitHub，開啟 Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access 選「Only select repositories」，只勾 本專案
  3. Permissions → Repository permissions → Contents 設為 Read and write，其他不用開
  4. 建議設到期日；產生後複製權杖貼到下面（權杖只會顯示一次）

2. 上傳或更新範本

選「📌 匯出範本」的 .json（多工作表表單一定要用這個）或單一工作表的 Excel 範本 .xlsx（可多選）。檔名就是表單名稱與網址；同名檔案會覆蓋成新版，分享連結不變。

3. 範本清單

每份範本對應一個固定的查填網址（名稱欄下方，可複製）。分類、說明、年度、截止日、隱藏改完按「儲存分類與說明」。隱藏的範本不列在首頁範本庫，但原本的連結照樣能用。存檔後約 1 分鐘首頁才會更新。

分享連結會變嗎？
  • 不變：用同一個檔名重新上傳（修改欄位、項目、公式）；改分類、說明、年度、截止日；設為隱藏
  • 會變：改名（舊連結失效）、刪除（連結失效）、GitHub 帳號或專案名稱改了（網址前半段都會變）
  • 建議：每年同一份調查可沿用同一張表，用「年度」欄區分；欄位每年不同就每年一個新檔名，舊年度設為隱藏。已寄出的連結盡量不要改名，改上傳新表單、把舊的隱藏。
