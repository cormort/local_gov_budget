範本與調查管理

發起與管理調查專案（期間、應繳機關），上傳、改名、刪除範本

1. 連線 GitHub

貼上 GitHub 存取權杖（token）才能新增、修改調查專案與範本。權杖只存在這個瀏覽器分頁，關掉分頁就清除；不會送到 GitHub 以外的地方。

怎麼取得權杖？
  1. 登入 GitHub，開啟 Settings → Developer settings → Fine-grained tokens → Generate new token
  2. Repository access 選「Only select repositories」，只勾 本專案
  3. Permissions → Repository permissions → Contents 設為 Read and write，其他不用開
  4. 建議設到期日；產生後複製權杖貼到下面（權杖只會顯示一次）

2. 調查專案

每次實際收件建一個專案：選範本、填發起單位、用途、期間與應繳機關。專案代號用在查填網址 ?survey=代號，建立後請不要再改（要改就新建一個專案）。改完下方清單按「儲存調查專案」，約 1 分鐘後首頁更新。

發起新調查

依 surveys/orgs.json 的標準順序帶入，再刪掉不需要的；回傳檔寫名單裡的簡稱（如「台電」「臺大醫」）、少了「基金」字尾或錯一兩個字，也會自動對上名單

3. 範本

上傳空白 Excel .xlsx（首頁「下載空白 Excel」與「貼表」用的就是這份，原檔照放即可），或進階網頁表單用的「匯出範本」.json（可多選）。檔名就是範本名稱；同名檔案會覆蓋成新版，用它的調查專案會自動用新版。
